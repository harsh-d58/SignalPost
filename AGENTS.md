# Signalpost repository instructions

At the start of every task in this repository, read [SIGNALPOST-RULES.md](SIGNALPOST-RULES.md). Use it when planning, editing, reviewing, testing, reporting metrics, or preparing a submission. Read [Builderr evaluation](BUILDERR-EVALUATION.md) for testing, metrics, and submission work. Before changing a connector, crawl path, evidence retention rule, or public export, read the [challenge source policy](SIGNALPOST-SOURCE-POLICY.md) and [repository source declarations](SOURCES.md).

Use the dated Builderr sources and run-specific instructions identified in the reference when a historical report, README section, or earlier plan disagrees. Record confirmed rule changes in the reference with their source and date. Keep competition requirements separate from internal promotion criteria and historical measurements.
